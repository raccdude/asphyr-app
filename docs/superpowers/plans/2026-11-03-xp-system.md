# XP and Rewards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace placeholder XP, levels, attributes and rewards with system-inferred rules that run on the device.

**Architecture:** Pure rule functions in one file, with difficulty estimation behind one swappable type. `QuestStore` applies the rules and records unlocks; screens only read results.

**Tech Stack:** SwiftUI, Observation, FoundationModels (conditional on Task 1), iOS 26.5 target.

**Spec:** `docs/XP-SYSTEM-SPEC.md`

## Global Constraints

- The developer runs all git commands and tests on the iPhone 18 Pro in Xcode. Claude never commits, and never drives a simulator.
- No backend, cloud AI, saving across relaunches, daily generation, daily XP cap or wearing cloaks.
- The project has no test target. Rule checks run as a throwaway script in the session scratchpad, compiling only the pure model files with `swiftc`. Each task ends with a successful `xcodebuild` for `generic/platform=iOS Simulator`.
- Update `docs/IMPLEMENTATION-NOTES.md` on this branch, and add each place the code passes Figma to "Figma updates for later". Don't edit Figma.

## Review Focus

- A title with both Hard and Easy words, like "Tidy my calculus notes": expect Hard.
- Words inside other words, like "walkthrough" against "walk", or capitals like "CALCULUS": match whole words, ignoring case.
- An empty or punctuation-only title while typing: expect Moderate, with no crash.
- Unticking a step across a level boundary: the level drops, and earned cloaks stay.
- One quest crossing levels 3 and 5: both cloaks are listed.

- Produces:

- [ ] **Step 1: Write the keyword checks in the scratchpad**

### Task 4: Store rules, levels and cloaks

**Files:**
- Modify: `Asphyr/Models/Quest.swift`, `Asphyr/Models/QuestStore.swift`

**Interfaces:**
- Consumes: `RewardRules`, `QuestDifficulty`
- Produces:
  - `Quest.difficulty: QuestDifficulty?` (replaces the `String?`)
  - `QuestStore.level`, `xpIntoLevel` and `xpForLevel`, read from `RewardRules.progress(totalXP: earnedXP)`
  - `QuestStore.unlockedCloaks: [CloakReward]`
  - `QuestCompletion.xpForLevel: Int` and `QuestCompletion.newCloaks: [CloakReward]`

- [ ] **Step 1: Apply the rules**

- `toggleStep` uses `RewardRules.xpPerStep(difficulty: quest.difficulty ?? .moderate)`.
- `complete` finds level changes by comparing `RewardRules.progress` at `earnedXP - xpReward` and at `earnedXP`, then adds any cloak in that range that isn't already in `unlockedCloaks`, and returns those as `newCloaks`.
- Unticking never removes from `unlockedCloaks`.
- Remove `QuestStore.xpPerLevel`. The sample quests keep their fixed values, with `.moderate` in place of `"MODERATE"`.

- [ ] **Step 2: Build**

Expected: fails only at screen call sites that Task 5 changes. Fix those minimally in Task 5.
